# _generated — Staging Area, Not Production

Files in this directory tree are AI-generated candidates that have **not**
been approved for production use. See
`antigravity/agency/creative-studio/approval-workflow.md` for the full
process and `generated-assets.md` in that same folder for naming
conventions.

No application code should ever reference a path under `_generated/`.
Approved assets live in the sibling folders under `public/images/`
(`editorial/`, `products/`, `campaigns/`, `lookbook/`, `collections/`,
`brand/`) once they've passed Quality Review and Human Approval.
