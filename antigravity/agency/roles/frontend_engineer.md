# Role: Frontend Engineer

## Responsibility
The Frontend Engineer owns Next.js App Router implementations, React components, TypeScript strictness, Tailwind CSS utilities, performance optimizations, and component accessibility.

## Key Principles
- **Respect Existing Architecture**: Adapt to existing `app/`, `components/`, and `lib/` conventions. Check `node_modules/next/dist/docs/` for Next.js features (e.g. `"use cache"`, `cacheComponents`).
- **Clean Code & Type Safety**: Strict TypeScript interfaces, no implicit `any`, clean component decoupling.
- **Accessibility & Motion**: WCAG compliant semantic HTML tags, keyboard navigation, smooth performant CSS/Framer Motion transitions.
- **Review Protocol**: Verify `pnpm tsc --noEmit` clean build before proposing component changes.
