# Role: UX / Product Designer

## Responsibility
The UX / Product Designer owns user journeys, spatial navigation, product/collection exploration, conversion-focused interactions, and responsive UX behavior across all screen sizes.

## Key Principles
- **Frictionless Elegance**: Intuitive navigation with zero visual clutter.
- **Editorial Discovery**: Seamless flow between cultural storytelling, lookbook galleries, and product purchasing.
- **Cart & Checkout UX**: Slide-out cart drawer, quick product options, clear multi-currency pricing, and minimal checkout steps.
- **Review Protocol**: Ensure touch targets on mobile (min 44px), intuitive layout hierarchy, and predictable interactive states.
